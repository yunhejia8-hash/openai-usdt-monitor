# risk_v9 验证记录（2026-09-29）

结论：本次完成规则一致性、成本警告和退出节奏的改进，**没有证明收益提升**。
候选规则在所选历史区间没有多头试仓，空头样本表现更差，因此不以它作为扩大风险暴露的依据；
监控输出明确标为研究候选，不能自动交易。不得用这段数据继续寻找“最好看的”阈值。

## 修正依据

- 线上旧版PROBE可在现价未收复支撑时成立，和低风险入场原则冲突。
- 已登记突破只限制正式确认，试仓分支仍可能绕过等待，现统一等待回踩。
- 总状态优先选择空头SETUP，可能掩盖多头PROBE；现先区分可入场候选与等待状态，冲突则观望。
- MA20偏离原用最近收盘价，可能与即时成交价不一致，现按本次价格判断。
- 原始R:R不计交易摩擦，现同时显示净R:R与敏感性；参数是研究假设，非账户费率。
- 开发中的旧支撑延续条件一度过宽，测试已发现并恢复为0.8 ATR附近保留；未发布该中间版本。
- 止盈目标动态移动前先检查旧目标是否已触发，避免错过阶段兑现。
- 没有真实持仓与成交阶段时不输出个性化卖出动作，也不把试仓信号当成买入成交。

## 限制

本区间曾参与策略开发，不是样本外数据；没有资金费、订单排队、真实冲击成本、精确强平模型。
同根双触及的净收益采用止损先到的保守假设，止损频率保留上下界。
快照每30分钟运行，盘中止损/止盈必须在执行端维护；动态目标与成交阶段不能由监控器猜测。
目前不足以评价完整策略年化收益、最大回撤或20倍杠杆后的账户收益。

使用本地工作区的 `backtest_results/candles.json`，确认上面的SHA-256：
```sh
python -m unittest -v
python -m py_compile monitor.py trade_risk.py replay_probe_risk.py
python replay_probe_risk.py --data ../backtest_results/candles.json --baseline baseline_monitor.py --output validation-results.json
```
